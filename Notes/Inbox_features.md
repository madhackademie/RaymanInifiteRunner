# Inbox features — vrac sans priorite

Ce fichier sert a vider les idees de feature sans les transformer en TODO, roadmap ou engagement de production.

Regles d'usage :
- une idee notee ici n'a **aucune priorite** ;
- pas de checkbox, pas d'estimation, pas de date cible ;
- on garde les idees meme floues, tant qu'elles peuvent inspirer plus tard ;
- on ne deplace une idee vers une spec ou une todo que sur demande explicite.
