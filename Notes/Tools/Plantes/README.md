# Fiches plantes (JSON)

Dossier canonique pour les exports / exemples de l’éditeur :

- **Chemin projet :** `Notes/Tools/Plantes/`
- **Exemple laitue :** `lettuce-fiche.json` (bouton « Exemple laitue » dans `fiche-plante-editor-v1.html`)

Dans l’éditeur :

- **Chemin ou URL — exemple laitue** : par défaut `Plantes/lettuce-fiche.json` (relatif au `.html` dans `Notes/Tools/`). Sur mobile ou vue GitHub, coller l’URL **Raw** du JSON si besoin.
- **Dossier JSON…** (Chrome/Edge desktop) : enregistrement direct dans ce dossier, secours si le `fetch` échoue.
