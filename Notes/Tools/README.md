# Outils carnet (hors Unity)

## Éditeur fiche plante (`fiche-plante-editor-v1.html`)

Outil navigateur pour rédiger des fiches alignées sur `PlantDefinition` + GDD (JSON export/import, atlas 7 stades, icône).

- **Ouvrir :** double-clic sur le HTML (Chrome / Edge recommandé pour le dossier JSON sur disque).
- **Copie à jour dans le Project Cursor :** Context → `docs/fiche-plante-editor-v1.html` (même contenu ; synchroniser vers ce dossier avant commit si tu édites dans Context).

Version courante : **v2.6** — bandeaux **Masquer / Afficher** + chevron ; exemple laitue : `Plantes/lettuce-fiche.json`.
