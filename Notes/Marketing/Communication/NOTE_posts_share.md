## FR vs EN

- Posts **EN** sur X, Bluesky, itch, Reddit, Shorts (titres search).
- **FR** : Facebook actuel, Discord FR, `#IndieFR` / `#gamedevfr` sur X, Discord Game Dev FR.
- Même visuel, légende courte bilingue si un seul post (EN + 1 ligne FR).

## Calendrier type (semaine)

Aligné sur le hub marketing :

| Moment | Quoi | Où |
|---|---|---|
| Jours 1–5 | 3 clips 15–25 s (pose, grille iso, récolte, HUD) | TikTok + Shorts + Reels + X + Bluesky |
| 1× / semaine | Recap = extraits du Devlog itch | X thread + Bluesky |
| J-1 du live | « Demain 21h, biofiltre iso » + GIF | X, Bluesky, Discord, FB FR |
| H-1 | Rappel + lien foyer | Discord + X |
| Go-live | Lien unique (YouTube ou Twitch) | Tous les canaux **sans** animer 4 chats |
| Après live | 1 GIF recap + lien VOD | X, Bluesky, Devlog itch si notable |

Heure et jour **fixes**. La régularité convertit plus que le multi-platforme.

## Clips (contenu)

Le biofiltre iso **est** le crochet. Sujets qui marchent :

- Pose plante / grille losange 2:1
- Croissance / récolte / HUD
- « Ce n’est pas un champ plat » (bac, IBC, hydro)
- 1 décision de design par clip, pas un changelog

Éviter : console Unity, stacktrace, « day 847 of making a game » sans visuel jeu.

Format : 9:16 pour TikTok/Shorts/Reels ; 16:9 recadré en plus pour X si besoin. **Un** fichier source, trois exports max.

## Discord

Serveur minimal :

- `#annonces` (lives + devlog)
- `#changelog` ou fil unique
- Lien itch (puis Steam)

Ne pas attendre 100 membres. C’est la liste de notif, pas un community-management.

## Boosters plus tard (pas semaine 0)

- **Steam Next Fest** — démo + live sur la fiche (build PC jouable).
- **Jams itch** — trafic de page même sans « gagner ».
- Listes cozy / wholesome / idle si le ton tient.
- Newsletter (Beehiiv / Buttondown) : audience **possédée**, quand itch a déjà un rythme.
- Presskit quand Coming Soon existe.

## Compte « tout coller »

Un **seul** lien public (page itch, plus tard Steam) dans la bio X, YT, Twitch, Discord, FB.

Ne pas empiler 4 « suivez-moi aussi sur… » dans chaque post.
