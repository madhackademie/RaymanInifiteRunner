# NOTE — Devblog

**Date :** 2026-09-16  
**Hub :** `Notes/Marketing/README_marketing.md`  
**Lié :** `NOTE_streaming.md` (annonce live dans un post) · `NOTE_posts_share.md` (recyclage clips)

Un **devlog** = texte court + 1–3 visuels (screenshot / GIF), cherchable, evergreen. Ce n’est pas un live, pas un Short.

## Où poster (retour réel)

Classement **joueurs + wishlist**, pas likes vides.

| Priorité | Plateforme | Pourquoi | Rôle |
|---|---|---|---|
| **1** | **itch.io** (page jeu + Devlog natif) | Meilleur foyer indie pre-Steam. Les followers reçoivent les posts. SEO, jams, « je suis en train de le faire ». | **Maison écrite** |
| **2** | **Steam News / Events** (dès *Coming Soon*) | Seul endroit qui convertit vraiment en wishlists. Un event live s’affiche sur la fiche. | Maison commerciale |
| **3** | **TikTok + YouTube Shorts + Reels** | Découverte 2026. Un GIF iso de 15–25 s bat un article de 1500 mots. | Recyclage visuel, pas le texte long |
| **4** | **X** | Village gamedev. Threads hebdo + « je live ». Pas un blog. | Amplification |
| **5** | **Bluesky** | Même contenu qu’X, moins de bruit, communauté indie active. | Copie X |
| **6** | **Reddit** (règles strictes) | Pics de trafic, pas une routine. Jamais le même copypasta partout. | Ponctuel |
| **7** | **YouTube long** | SEO à 6–18 mois. Les lives YT deviennent des « Devlog #N ». | Archive / search |
| **8** | **IndieDB + TIGSource** | Faible volume, bon Google / vétérans. ~20 min / mois. | SEO résiduel |

**Ne pas traiter comme foyer :** Medium, LinkedIn (réseau pro, pas joueurs), Facebook public (sauf audience FR déjà là).

## Cadence

- **1 devlog écrit / semaine** sur itch (recopié Steam News plus tard).
- **3–5 clips courts** la même semaine, à partir du même footage (voir `NOTE_posts_share.md`).
- Longueur itch : **200–400 mots** + 1 décision de design + 1 visuel fort. Pas un journal de debug Unity.

## Foyer itch (maintenant)

Créer la page **même en *In development*** : pas besoin d’attendre un build public.

À coller sur la page :

- Pitch 2 phrases (biofiltre / hydro iso cartoon).
- 3–6 captures (grille, HUD, plante, atelier si présentable).
- Lien Discord + calendrier live (ou « lives : voir Devlog »).
- Lien Twitch / YouTube (itch **n’a pas** de live natif — voir `NOTE_streaming.md`).

Chaque update gameplay = un **Devlog** itch, pas seulement un changement de description.

## Steam (dès Coming Soon)

- Recopie du post itch en **News**.
- Event **Live-Stream / Broadcast** pour les sessions (détail technique dans `NOTE_streaming.md`).
- CTA unique : **wishlist**, pas une liste de réseaux.

Coming Soon = trailer + captures + texte. **Pas de build jouable obligatoire** pour la fiche ni pour le news.

## Langue

- **EN d’abord** (10× l’audience indie itch / Steam / Reddit / X).
- Une ligne ou un paragraphe **FR** pour l’audience déjà sur Facebook / Discord FR.
- Titres EN stables (`Devlog #N — Iso biofilter grid`) pour le search.

## Structure type — Devlog #1

Titre EN : `Devlog #1 — Hydro farm, isometric biofilter (not another flat field)`  
Titre FR (sous-titre) : `Ferme hydro, biofiltre iso — pas un champ plat`

1. **Hook visuel** — GIF ou screenshot grille iso + bac, dès la première ligne.
2. **C’est quoi** — 3 phrases : aquaponie / biofiltre, iso 2:1 cartoon, boucle planter → croître → vendre.
3. **Une décision de design** — ex. grille losange 2:1, HUD nested, pas de moule unique.
4. **Où en est-on** — honnête (prototype Unity, mobile playtest, pas un trailer marketing).
5. **Live** — jour + heure + lien foyer (YouTube ou Twitch).
6. **CTA** — follow itch / Discord ; plus tard wishlist Steam.

Ne pas ouvrir sur « Unity 6 WIP » ou une liste de bugs.

## Reddit (si un post devlog)

Sous-fits utiles, **un par un**, en respectant les règles de promo :

- `r/IndieDev`, `r/solodevelopment`
- Gameplay : `r/incremental_games`, `r/IdleGame`, `r/cozygamers` (si le ton cozy tient)
- Technique : `r/Unity3D` seulement si le post est vraiment technique

Jamais le même texte le même jour sur 5 subs. Pas de lien Steam/itch en titre si le sub l’interdit.
