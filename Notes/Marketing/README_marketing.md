## Principe (ne pas diluer)

Le levier n’est pas « poster partout ». C’est **un foyer écrit + une machine à clips + un calendrier live**.

| Rôle | Où |
|---|---|
| Vérité écrite (devlog) | **itch.io** maintenant ; **Steam News** dès Coming Soon |
| Découverte | TikTok + YouTube Shorts + Instagram Reels (même clip 15–25 s) |
| Village gamedev | X + Bluesky |
| Live | **1 foyer** (YouTube recommandé) ; restream technique ailleurs |
| Rétention | Discord du jeu (même petit) |
| Conversion | **Wishlist Steam** dès la fiche ; d’ici là page itch + follow Discord |

CTA unique par période : un seul lien à coller partout (itch, puis wishlist Steam). Pas « follow 4 réseaux ».

## Hook à vendre

Ferme **hydro / biofiltre**, vue **iso 2:1 cartoon** (Township / The Tribez, volume = bacs, pas champ plat).  
Le crochet public = le biofiltre iso, pas « Unity WIP ».

## Plan 4 semaines (rappel)

**Semaine 0**

- Page itch *In development* + Devlog #1.
- X + Bluesky bilingue (EN d’abord, une ligne FR).
- Discord minimal (annonce live + changelog).
- Un lien unique (page itch / Linktree) collé partout.

**Chaque semaine**

- 1 post itch (screenshot + 1 décision de design, 200–400 mots).
- 3 clips 15–25 s (pose plante, grille iso, récolte, HUD).
- 1 live daté (même jour, même heure), titre du type *« Biofiltre + grille iso — session N »*.
- 3 posts live : J-1, H-1, go-live.

**Dès fiche Steam**

- Recopie du devlog en News.
- Event live Steam + restream OBS.
- CTA = wishlist.

## À ne pas faire

- Animer 4 chats live (Facebook + Twitch + YouTube + Kick) comme 4 foyers.
- Blog WordPress / Medium comme maison.
- Attendre que le jeu soit « présentable ».
- Kick ou Facebook comme moteur de découverte EN.
- X Live ou itch comme plateforme de stream principale.

## Hors périmètre (plus tard)

- Steam Next Fest = **démo PC** jouable (autre chantier que le live Coming Soon).
- Port Windows public = vente / Next Fest, pas un prérequis pour streamer sur Steam.
